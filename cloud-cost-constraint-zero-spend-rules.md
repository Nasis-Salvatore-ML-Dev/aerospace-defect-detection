The portfolio is private now and goes public after all 5 phases complete. Recruiters will evaluate it. Standard is top-tier ML engineer hire quality — no tutorial-grade shortcuts.
Hard constraint — zero cloud spend. The original GCP $300 free trial is exhausted on the primary Google account. Creating a second free trial under any new identity (new email, different phone number, same person) violates Google's Free Trial Terms ("only new GCP customers are eligible") and risks account suspension. That path is closed. Therefore every cloud-touching step in Days 3–24 must cost literally zero on the primary GCP account (already used trial → currently no credits, no billing enabled).
Rules for every cloud recommendation in this project:

GCP usage limited to Always Free tier on existing account. Allowed: Cloud Run (2M req/month, 360k vCPU-sec, 180k GiB-sec free), Cloud Storage (5 GB in us-east1/us-west1/us-central1 only — not europe-west1, which is paid), Cloud Logging (50 GiB/month), Cloud Functions, Pub/Sub, Firestore (1 GiB), Artifact Registry (0.5 GB free). Off-limits unless explicitly free-tier eligible: Vertex AI (training, endpoints, pipelines, workbench), Cloud SQL, GKE, Composer, Dataflow, Dataproc, BigQuery beyond 1 TB queries/month, any GPU/TPU on GCP, Cloud Build beyond 120 build-min/day.
Region matters. The Day 2 Block 2 instructions used europe-west1 for Artifact Registry — that is not in the always-free zone. When GCP setup happens, switch to us-central1 (or another always-free region) for Artifact Registry, Cloud Storage, and Cloud Run. Mention this explicitly when proposing gcloud commands.
No second free trial, no payment method workaround. Do not propose creating a new Google account, using a different phone number, or adding a credit card "just for verification." The project must work without enabling billing on any GCP account. If a step requires billing to be enabled (some APIs do), flag it clearly and propose a free-tier-only alternative.
Deep learning compute (GPU/TPU) — never on GCP. EfficientNetB0 fine-tuning and any DL training that needs a GPU must run on Google Colab free tier (T4 GPU, ~12h sessions) or Kaggle Notebooks (P100/T4 GPU, 30h/week quota). Save artifacts (model weights, ONNX exports, training logs) to GCS free tier or to W&B. Never propose Vertex AI Training, Vertex Workbench, or any paid GPU instance.
Experiment tracking. Use Weights & Biases free personal tier (unlimited public projects, generous storage) — industry-standard, recruiter-recognizable, integrates cleanly with Keras/TF. Alternative: local MLflow with SQLite backend + GCS artifact store (free-tier GCS bucket). Do not propose Vertex AI Experiments.
Orchestration. Use GitHub Actions for the entire MLOps loop — it's free for public repos and 2000 min/month for private. Cron-triggered retraining, eval-gate workflow, deploy workflow. Do not propose Cloud Composer, Vertex Pipelines, or any managed orchestrator. If Airflow/Prefect demonstration is needed for portfolio depth, run them locally in Docker only and document in the README how they would deploy to managed services in production.
Serving = Cloud Run only. Already aligned with Day 2 plan. Stay within free tier (2M req/month is enormous for a portfolio demo). Set min instances = 0 (scale-to-zero) to guarantee zero idle cost. Do not propose GKE, Cloud Functions Gen2 with min instances, or anything with persistent compute.
CI/CD = GitHub Actions + Workload Identity Federation to GCP (the same pattern from the BMW pricing project — keyless auth, no long-lived service account JSON in repo). Do not propose Cloud Build as the primary CI; it has free quota but eats into it fast and is harder to demonstrate in a portfolio repo. Cloud Build can be mentioned in the README as "alternative pattern" without being implemented.
Monitoring. Cloud Logging + Cloud Monitoring free tier (50 GiB logs/month). Drift detection: implement in Python inside a scheduled GitHub Action, log results to GCS, surface via a simple Streamlit dashboard hosted on Streamlit Community Cloud (free) or as a static report committed to the repo. Do not propose Vertex AI Model Monitoring.
Always state cost implications. Every architectural proposal must explicitly confirm "this stays within free tier" and flag accidental-charge risks (egress > 1 GB/month, wrong region, idle resources, storage class transitions, Cloud Build overage, log volume). Propose a $0 GCP budget alert as a hard guardrail (alerts at $0.01) — Day 2 Block 2 said $10 budget; change to $1 with alerts at 50% and 90% so any leak is caught immediately.
Other free clouds welcome if useful. Oracle Cloud Always Free (4 ARM Ampere VMs, 24 GB RAM, persistent — excellent for an always-on demo or self-hosted MLflow), GitHub Codespaces (60 free hours/month). Multi-cloud is a CV plus, not a problem.
